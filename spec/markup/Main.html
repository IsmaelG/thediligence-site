Specialists, not a chatbot

One agent per question: market, company, product, technology, first 100 days. Each runs the open method in its own sandbox with a clean context.

A ledger, not a transcript

Every claim carries a source id and a grade, A, B or C. A claim with no source cannot be written, unless it is flagged as an estimate.

A verifier that is not the writer

A second model family reviews the memo against the evidence rules and lists what it could not check. One vendor’s blind spot stays out of your memo.

Agents and people, one workflow

Agents plan, read and draft. People decide, and nothing leaves without one. Gates reach you by email, and soon your own agents and assistants join through MCP.

Cost control

Plan it. Price it. Then run it.

No run starts without a plan you have seen. Every agent has a price before it starts working, so the memo never surprises the bill.

  • Priced per agent, before launch. Costs come from each agent’s profile and the list prices of the providers you connected.
  • A budget cap the run obeys. Set the ceiling in the plan. A run that would cross it stops and delivers what exists.
  • Estimate against actual. After each run you see the drift, agent by agent, so the next estimate is closer.
  • Updates priced to what changed. New evidence rebuilds only the sections it touches, and shows that cost first.

Security and compliance

Built for data that cannot leave the building.

Your connections, your notes and your target’s files each have a rule, and the rule is enforced by the architecture, not by a promise.

At launch

No key in a sandbox

Agents get a short-lived run token. You connect your provider on its own screen where it allows it, and a broker enforces the budget. A pasted key, where there is no other way, is encrypted and never visible to agents.

At launch

A vault that agents cannot read

Term sheets and partner notes live in a vault we host and cannot read, encrypted in your browser. Prefer Obsidian? A plugin keeps them there, from Pro. A note reaches an agent only when you share it, for one target.

Next

Europe-only mode

European hosting and model routing restricted to European regions, for funds whose data must stay in Europe.

At launch

Nothing leaves without a person

Agents have no tool that sends, posts or emails. They draft. Every export and every outreach is yours to approve.
