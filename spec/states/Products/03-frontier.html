01 · Plan

Know the cost before you build the memo.

No run starts without a plan you have seen. The coordinator drafts it in seconds: the sequence of agents, what each one will cost, what it still needs from you, and where it will stop for your approval.

  • Every agent has a price. Estimated from the agent’s own profile and the list prices of the providers you connected.
  • Change a model, watch the total move. Pick Economy, Balanced or Frontier, or set a tier agent by agent.
  • A cap the run obeys. If a run would cross your budget, it stops and delivers what exists, with a list of what is missing.
  • Estimate against actual. After the run, each agent shows its drift, and its profile updates itself.

Already available

What the agents find themselves

Public sources the agents fetch, and whatever you ticked when you created the target: a deck, a website, filed accounts.

Great to have

What changes the verdict

Management accounts, a revenue export of 18 months or more, customer interviews, access to the product. Without them the plan says which sections will carry C grades.

Nice to have

What sharpens it

Analyst reports, references, a penetration test. Add them now or when they arrive: new evidence only rebuilds what it touches.

The plan is saved with the target. Save it and run it later, or edit the steering note to tell the coordinator what to weigh. Every plan is stored as the first version of the run’s spec.
